# FAQ-accordion

A simple and responsive **FAQ Accordion** built using HTML, CSS, and JavaScript.

Users can click on a question to expand its answer and click again to collapse it. Only one FAQ answer remains open at a time.

## 📌 Project Overview

The FAQ Accordion is an interactive user interface component that displays frequently asked questions.

Instead of showing all answers at once, users can click a question to view its answer. This creates a clean and user-friendly experience.

## 🎯 Objective

The main objective of this project is to practice:

- DOM manipulation
- JavaScript event handling
- `classList.toggle()`
- Button click events
- CSS transitions
- Responsive web design
- Interactive UI components
